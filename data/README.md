# 서울시 동물병원 인허가 데이터

담당자: 이승훈

## 출처와 파일

- 제공기관: 서울특별시
- 데이터: [서울 열린데이터광장 — 서울시 동물병원 인허가 정보](https://data.seoul.go.kr/dataList/OA-16007/S/1/datasetView.do)
- 이용 조건: 공공누리 제1유형, 출처표시
- 저장 파일: `data/seoul_animal_hospitals.csv`
- 저장 인코딩: UTF-8 BOM (`utf-8-sig`)
- 팀에 제공된 원본 인코딩: CP949
- 원본 제공일: 2026-11-01, 저장소 업로드일: 2026-11-03. 정확한 다운로드 날짜는 확인되지 않았습니다.
- 포함된 행의 최대 데이터갱신일자: 2026-10-30 22:03:08. 이는 파일 안의 최댓값이며 모든 행의 기준일을 의미하지 않습니다.

한글을 읽기 쉽도록 인코딩만 UTF-8 BOM으로 변환했습니다. 원본의 값·행·열은 그대로이며, 전처리 완료 데이터가 아닙니다. 프로그램 실행 시 HospitalRepository가 pandas로 전처리합니다.

## 제공 파일 현황

| 구분 | 건수 |
|---|---:|
| 전체 | 2,242 |
| 정상 영업 | 985 |
| 휴업 | 10 |
| 폐업 | 1,241 |
| 기타 상태(말소) | 6 |

정상·휴업 995건 중 원본 좌표가 없는 병원은 12건입니다. 폐업 데이터 중 충청남도 주소인 1건은 자치구를 임의로 지정하지 않고 `지역 미확인`으로 분류합니다. 상태는 원본의 행정상 영업상태이며 실시간 진료 여부가 아닙니다.

## 사용 열과 전처리 기준

- `관리번호`, `사업장명`: 병원 식별에 사용합니다. 누락 행은 제외하며, 관리번호 중복은 첫 행을 유지합니다.
- `영업상태코드`, `영업상태명`: 01=정상 영업, 02=휴업, 03=폐업으로 통일합니다. 다른 코드는 기타 상태로 관리하고, 코드가 비어 있으면 상태명을 확인합니다.
- `전화번호`: 누락돼도 병원을 유지하고, 말풍선 표시 때 ‘정보 없음’으로 안내합니다.
- `도로명주소`, `지번주소`: 도로명주소 우선, 없으면 지번주소를 사용합니다. 두 주소에서 서울 자치구를 추출합니다.
- `좌표정보(X)`, `좌표정보(Y)`: 숫자로 변환하며 비정상 값은 누락값으로 처리합니다. 원본 좌표계는 서울시 공식 안내의 EPSG:5174입니다.

문자열로 읽어 관리번호·전화번호의 앞자리 0을 보존하고, 값과 열 이름의 앞뒤 공백을 제거합니다. 빈 셀과 필드가 부족한 행은 구분합니다. 필드 부족·필수값 누락 행은 제외 건수를 기록하고, 열 과다·깨진 따옴표 등 안전하게 읽을 수 없는 파일은 오류로 안내합니다.

폐업·기타 상태도 저장소에는 보관합니다. 지도에는 정상·휴업만 선택하고 유효한 위경도가 있는지 확인해야 합니다. 좌표가 없는 병원을 임의 위치에 표시하지 않습니다.

위치 서비스가 미연결된 상태에서는 원본 X/Y만 보관하고 위도·경도는 `None`으로 둡니다. `LocationService.convert_coordinates(x, y)`를 연결하면 반환된 `(위도, 경도)`를 저장합니다. 원본 X/Y를 위경도로 사용하면 안 됩니다.

실행 예시와 반환 형식은 [클래스 연결 안내](../docs/data_classes.md)를 참고하세요.
