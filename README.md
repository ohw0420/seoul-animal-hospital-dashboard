# 서울시 동물병원 지도

객체지향프로그래밍 11조 팀 프로젝트입니다.
서울시 동물병원 인허가 정보를 활용하는 지도 기반 대시보드를 개발합니다.

## 현재 진행 상태

클래스 기본 파일을 생성한 초기 단계입니다. 실제 기능과 실행 방법은 구현 후 추가합니다.

## 구현 예정 기능

- 서울시 자치구별 동물병원 수 표시
- 자치구별 병원 조회 및 지도 표시
- 정상영업·휴업 상태별 마커와 병원 상세정보 표시
- 주소 입력을 통한 사용자 위치 설정
- 지정 반경 내 동물병원 검색

## 역할 분담

| 담당자 | 클래스 | 역할 |
|---|---|---|
| 이승훈 | AnimalHospital, HospitalRepository | 병원 데이터 로딩, 객체 관리, 자치구별 조회·집계, 반경 검색 |
| 정부성 | LocationService, UserLocation | 주소·좌표 변환, 거리 계산, 사용자 위치 관리, 발표 |
| 오현우 | HospitalMapView | 지도·마커·팝업·검색 반경 표시, 보고서 |
| 이지운 | DashboardController | 사용자 입력 처리, 클래스 연결, PPT |

## 폴더 구성

- src: Python 클래스 코드
- data: 동물병원 데이터와 출처 기록
- docs: 클래스 설계, 발표 자료, 보고서

## 사용 데이터

서울시 동물병원 인허가 정보입니다. 다운로드 주소, 기준일, 사용 항목은 data/README.md에 기록합니다.

## 실행 방법

아직 실행 기능이 구현되지 않았습니다. 개발 환경, 필요 패키지, 실행 명령은 구현 후 작성합니다.

## 협업 방법

1. 기능별 작업 브랜치를 만듭니다.
2. 담당 파일을 수정하고 실행 결과를 확인합니다.
3. 변경 내용을 업로드하고 main으로 Pull Request를 만듭니다.
4. 다른 팀원이 검토한 후 합칩니다.
5. 변경된 공통 코드를 받아 다음 작업을 진행합니다.

클래스 간 메서드 이름, 좌표 순서, 반환 형식은 구현 전에 함께 합의합니다.
