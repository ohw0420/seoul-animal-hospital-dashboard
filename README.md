# 서울시 동물병원 지도

객체지향프로그래밍 11조 팀 프로젝트입니다.
Python과 pandas로 서울시 동물병원 인허가 데이터를 처리하고, 지도 기반 대시보드를 개발합니다.

## 현재 상태

개발 시작을 위한 기본 구조입니다. 클래스는 구현 전 기본 틀이며, 실행 가능한 대시보드는 아직 없습니다.
지도와 화면 도구는 팀에서 결정한 후 필요한 패키지를 추가합니다.

## 개발 환경 준비

Python 설치 후 이 프로젝트 폴더에서 다음 명령으로 패키지를 설치합니다.

```sh
python -m pip install -r requirements.txt
```

pandas는 데이터 처리 도구입니다. 지도 화면은 별도의 도구로 구현합니다.
실행 파일과 대시보드 실행 방법은 구현 후 추가합니다.

## 역할 분담

| 담당자 | 클래스 | 주요 역할 |
|---|---|---|
| 이승훈 | AnimalHospital, HospitalRepository | pandas 데이터 로딩·정리, 병원 객체 생성, 자치구별 조회·집계, 반경 검색 |
| 정부성 | LocationService, UserLocation | 주소·좌표 변환, 거리 계산, 사용자 위치 관리, 발표 |
| 오현우 | HospitalMapView | 지도, 마커, 팝업, 반경 표시, 보고서 |
| 이지운 | DashboardController | 사용자 입력 처리, 객체 연결, PPT |

## 폴더 구성

- src: 클래스 코드
- data: 병원 데이터 및 출처 기록
- docs: 클래스 설계, 발표 자료 및 보고서
- requirements.txt: 필요한 Python 패키지
- .gitignore: 임시 파일 및 개인 환경 파일 제외

## 사용 데이터

서울시 동물병원 인허가 정보입니다.
원본 데이터는 아직 포함하지 않았습니다. 출처, 기준일, 인코딩, 사용 열과 처리 기준은 data/README.md에 기록합니다.

## 구현 예정 기능

- 자치구별 병원 수 집계 및 지도에 원 크기로 표시
- 자치구별 병원 조회
- 정상영업 초록색, 휴업 빨간색 표시 및 폐업 제외
- 병원명·상태·전화번호·주소 팝업
- 주소 입력으로 사용자 위치 설정
- 지정 반경 내 동물병원 검색

## 데이터 처리와 객체 간 상호작용 계획

HospitalRepository에서 pandas로 데이터를 읽고 정리한 뒤 AnimalHospital 객체를 생성합니다.
LocationService는 병원 좌표와 사용자 주소를 지도용 좌표로 변환합니다.
DashboardController는 사용자 입력에 따라 데이터를 조회하고 HospitalMapView에 전달합니다.
UserLocation은 현재 사용자 위치를 관리합니다.

구현 전 CSV 열 이름, 인코딩, 좌표계, 메서드 이름, 반환 형식을 합의합니다.
세부 메서드와 실제 동작 흐름은 구현 후 문서에 반영합니다.

## 협업 방법

1. 담당 기능의 작업 브랜치를 만듭니다.
2. 담당 파일을 수정하고 실행 결과를 확인합니다.
3. 변경 내용을 올리고 main으로 Pull Request를 만듭니다.
4. 다른 팀원이 검토하고 통합 실행을 확인한 뒤 합칩니다.
5. 최신 main을 받아 다음 작업을 진행합니다.


## 지도 실행 방법

### 1. 최초 환경 설정

Python을 설치하고, 프로젝트를 내려받아 압축을 풉니다.

`demo_map.py`, `requirements.txt`, `web.bat`이 있는 폴더를 VS Code로 열고 터미널에서 다음 명령을 순서대로 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

이 과정은 처음 한 번만 진행합니다. 필요한 패키지가 변경되면 설치 명령을 다시 실행합니다.

### 2. 카카오 지도 키 설정

프로젝트 최상위의 `.env.example`을 복사하여 `.env`로 이름을 바꾸고, 카카오 JavaScript 키를 입력합니다.

```dotenv
KAKAO_JAVASCRIPT_KEY=본인의_JavaScript_키
```

카카오 개발자 앱에서 지도 사용 설정과 `http://localhost:8000` 도메인 등록을 완료해야 합니다.

`.env`와 `.venv`는 GitHub에 업로드하지 않습니다.

### 3. 지도 실행

Windows 탐색기에서 프로젝트 폴더의 **`web.bat`을 더블클릭**합니다.

실행 창에 접속 주소가 표시되면 브라우저에서 다음 주소를 엽니다.

http://localhost:8000

화면을 사용하는 동안 실행 창은 켜두세요. 인터넷 연결이 필요합니다.

### 4. 종료 및 재실행

실행 창에서 `Ctrl+C`를 눌러 서버를 종료합니다. 브라우저 탭만 닫으면 서버는 계속 실행됩니다.

코드를 수정한 뒤에는 저장하고 서버를 종료한 다음 `web.bat`을 다시 실행하세요. 브라우저에서 `Ctrl+F5`로 새로고침합니다.

### 현재 시연 범위

광운대학교 부근의 사용자 위치, 가상 병원 3개, 상태별 마커, 상세정보 팝업과 1km 반경을 표시합니다. 실제 병원 데이터 및 반경 검색은 아직 연결하지 않았습니다.
