# 설계 및 발표 자료

클래스 관계도, 객체 간 처리 흐름, 발표 자료, 보고서를 보관합니다.

- 클래스 설계 및 인터페이스 합의: 전원
- 발표 및 시연 준비: 정부성
- PPT 제작: 이지운
- 보고서 작성: 오현우

## 중간발표 시제품 목표

실제 병원 데이터 일부를 불러와 지도에 마커를 표시하고, 클릭하면 병원명과 주소가 보이도록 연결합니다.
현재 기능 구현이 완료됐다는 의미가 아닌 개발 목표입니다.

## 이후 개발 목표

자치구 선택·집계, 영업 상태 표시, 사용자 주소 검색, 사용자 위치 표시, 거리 계산과 반경 검색을 연결합니다.
